masks signs people in to your apps. It is an OpenID Connect and OAuth 2.0 provider, which means it
speaks the standard protocols that apps use to sign people in and get tokens.

## Try it locally

The repository runs masks, Postgres, and this documentation on your computer with `./dev`. You need
Ruby, and [Colima](https://github.com/abiosoft/colima) with Compose.

1. Clone the repository and start the stack:

   ```sh
   git clone https://github.com/masksrb/masks.git
   cd masks
   ./dev
   ```

2. Open masks at `http://masks.localhost:12345`.
3. Enter the setup token `masks-dev`, and follow the **Set up** screen. See
   [setting a tenant up](/guides/core-concepts/#setting-a-tenant-up) for each step.

The account you create holds `masks:manage`. Choose **Manage this server** on your account page to
open `/manage`.

This documentation runs at `http://masks.localhost:12346`.

`./dev` takes these commands:

| Command                |                                                                                                                      |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `./dev`                | Builds and runs the stack in the foreground.                                                                         |
| `./dev down`           | Stops the stack and keeps its data.                                                                                  |
| `./dev reset`          | Deletes the data and starts again at the **Set up** screen.                                                          |
| `./dev logs [service]` | Follows the logs of one service, or all of them.                                                                     |
| `./dev console`        | Opens a Rails console.                                                                                               |
| `./dev psql`           | Opens `psql` on the database.                                                                                        |
| `./dev test [suite]`   | Runs the test suites in containers: `unit`, `integration`, `provider`, `engine`, `client`, `web`, and `conformance`. |
| `./dev image`          | Runs the production image and checks it. See [the demo](/demo/#run-the-production-image).                            |
| `./dev --multi`        | Runs two tenants, `demo` and `acme`. See [the demo](/demo/).                                                         |

The ports are in [environment variables](/reference/environment/#the-dev-stack).

## Run it in production

masks runs in one of three ways.

|                                              |                                                                                          |
| -------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [The container image](/guides/self-hosting/) | `ghcr.io/masksrb/masks`, with a Postgres server and a TLS proxy in front of port `3000`. |
| [Engine mode](/reference/ruby/engine-mode/)  | Mounted inside your own Rails app with the `masks-server` gem.                           |
| [Server mode](/reference/ruby/server-mode/)  | A Rails app of your own that is a masks server and nothing else.                         |

Each one starts at the same **Set up** screen, with a setup token that masks prints when it creates
the tenant.

## Connect an app

An app connects to masks through an SDK, a library for the app's language. masks has SDKs for
Ruby, JavaScript in the server and in the browser, Python, and Go.

1. Pick the SDK in [choosing an SDK](/guides/connecting-via-sdk/#choosing-an-sdk).
2. Follow [connecting an app](/guides/connecting-via-sdk/#connecting-an-app).
