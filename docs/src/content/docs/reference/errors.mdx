---
title: Errors
description: The errors every masks SDK raises, with the kind, the code, and the description each failure gets.
---

Every SDK raises the same error for the same failure. The kinds, the codes, and the descriptions
below come from one table, [`test/contract/errors.json`](https://github.com/masksrb/masks/blob/main/test/contract/errors.json),
and each SDK ships a copy generated by `./dev reference`. CI fails when a copy or this page drifts
from the table.

Every error's message reads `masks: {code}: {description}`. A failure the table lists gets the description in the
last table, with the parts in braces filled in.

## Kinds

| Kind | Means | Code | Carries |
| --- | --- | --- | --- |
| `Refused` | masks answered a request with an OAuth error, or the SDK found the answer unusable. | the code masks answered with, or server_error when the answer was not an OAuth error | `code`, `description`, `uri`, `status` |
| `InvalidToken` | A token, an ID token, a logout token, or a DPoP proof failed a check in the SDK. missing says the request carried no token at all, and a resource server's challenge then carries no code. | invalid_token for a token, invalid_dpop_proof for a proof | `code`, `description`, `missing` |
| `Forbidden` | The sign-in or token is valid and lacks a scope, a role, or an organization the route needs. | insufficient_scope, insufficient_role, or insufficient_organization | `code`, `description`, `scope` |
| `Unavailable` | masks, its keys, or a store the SDK depends on could not be reached, so nothing can be decided. | temporarily_unavailable | `code`, `description` |
| `Insecure` | A URL is plain http off this machine, or is not an http or https URL at all. | insecure_url | `code`, `description` |
| `Foreign` | A URL belongs to another origin than the one the tokens are held for. | foreign_origin | `code`, `description` |
| `DelegationRefused` | masks refused a delegation call. sign_in_again says the person has to sign in again, and secret carries a replacement secret when masks rotated it. | the code masks answered with | `code`, `description`, `status`, `secret`, `sign_in_again` |
| `DelegationUnavailable` | masks or the provider did not answer a delegation call. secret carries a replacement secret when masks rotated it before failing. | temporarily_unavailable | `code`, `description`, `secret` |

Each kind spells its name the way its language does. A dash means the SDK has no such call.

| Kind | Ruby | JavaScript | Browser | Python | Go |
| --- | --- | --- | --- | --- | --- |
| `Refused` | `Masks::Client::Rejected` | `Refused` | `Refused` | `masks.Refused` | `*masks.Refused` |
| `InvalidToken` | `Masks::Client::InvalidToken` | `InvalidToken` | `InvalidToken` | `masks.InvalidToken` | `*masks.InvalidToken` |
| `Forbidden` | `Masks::Client::Forbidden` | `Forbidden` | – | `masks.Forbidden` | `*masks.Forbidden` |
| `Unavailable` | `Masks::Client::Unreachable` | `Unavailable` | – | `masks.Unavailable` | `*masks.Unavailable` |
| `Insecure` | `Masks::Client::Insecure` | `Insecure` | `Insecure` | `masks.Insecure` | `*masks.Insecure` |
| `Foreign` | `Masks::Client::Foreign` | `Foreign` | – | `masks.Foreign` | `*masks.Foreign` |
| `DelegationRefused` | `Masks::Client::Delegations::Refused` | `DelegationRefused` | – | `masks.DelegationRefused` | `*masks.DelegationRefused` |
| `DelegationUnavailable` | `Masks::Client::Delegations::Unavailable` | `DelegationUnavailable` | – | `masks.DelegationUnavailable` | `*masks.DelegationUnavailable` |

## Codes

| Code | From | Means |
| --- | --- | --- |
| `invalid_request` | masks | The request is missing a parameter, repeats one, or is malformed. |
| `invalid_client` | masks | The client is unknown, or its credentials did not check out. |
| `invalid_grant` | masks | The code, refresh token, or assertion is invalid, expired, revoked, or was issued to another client. |
| `unauthorized_client` | masks | The client may not use this grant type or this endpoint. |
| `unsupported_grant_type` | masks | masks does not support that grant type. |
| `unsupported_response_type` | masks | masks does not support that response type. |
| `invalid_scope` | masks | A scope asked for is unknown, malformed, or more than the client may hold. |
| `access_denied` | masks | The person or masks refused the request. |
| `server_error` | masks | masks failed, or answered with something the SDK could not read. |
| `temporarily_unavailable` | masks | masks, or something the SDK depends on, is not answering for now. |
| `login_required` | masks | Nobody is signed in, and the request asked masks not to prompt. |
| `interaction_required` | masks | masks needs the person to do something, and the request asked it not to prompt. |
| `consent_required` | masks | The person has not allowed this app in, and the request asked masks not to prompt. |
| `invalid_token` | masks | The access token is expired, revoked, malformed, or was issued for another resource. |
| `insufficient_scope` | masks | The token is valid and does not carry a scope the request needs. |
| `insufficient_role` | the SDK | The sign-in is valid and the person does not hold a role the route needs in the organization signed in to. |
| `insufficient_organization` | the SDK | The sign-in is valid and names no organization, or another one than the route needs. |
| `invalid_dpop_proof` | masks | The DPoP proof is missing, malformed, signed by the wrong key, made for another request, or used before. |
| `use_dpop_nonce` | masks | The DPoP proof needs the nonce masks sent in the DPoP-Nonce header. |
| `slow_down` | masks | The device is polling faster than masks allows. |
| `authorization_pending` | masks | Nobody has approved the device code yet. |
| `expired_token` | masks | The device code expired before anyone approved it. |
| `invalid_target` | masks | The resource asked for is unknown, or not one the client may reach. |
| `invalid_client_metadata` | masks | A registration names metadata masks refuses. |
| `invalid_request_object` | masks | The request object is malformed or its signature did not check out. |
| `invalid_authorization_details` | masks | The authorization details are malformed or ask for more than the client may hold. |
| `invalid_key` | masks | A key sent to masks is malformed, private, or signs with an algorithm masks refuses. |
| `invalid_audience` | masks | A token names an audience masks does not serve. |
| `invalid_issuer` | masks | The issuer named is unknown, or its discovery document does not describe it. |
| `invalid_state` | the SDK | The state that came back is not the one this sign-in started with. |
| `invalid_style` | the SDK | The issuer does not serve avatars in that style. |
| `handshake_required` | the SDK | This app has not shaken hands with its issuer, so it holds no credentials. |
| `insecure_url` | the SDK | A URL is plain http off this machine, or is not http or https. |
| `foreign_origin` | the SDK | A URL belongs to another origin than the one the tokens are held for. |
