One palette and one type stack for the sign-in and account pages, `/manage`, this site, and the Ruby
API docs. Light and dark mode follow the system setting.

| Where | File |
| --- | --- |
| Sign-in, account pages, and `/manage` colors | `server/app/frontend/entrypoints/app.css` |
| `/manage` layout | `server/app/frontend/entrypoints/console.css` |
| This site | `docs/src/styles/global.css` |
| Ruby API docs | `client/doc/rose.css` |

## Type

Text:

```css
font-family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
```

Code:

```css
font-family: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace;
```

| | Size | Line height |
| --- | --- | --- |
| `/manage` small | `0.8125rem` (13px) | 1.45 |
| `/manage` body | `0.875rem` (14px) | 1.5 |

## Radius

| | Box | Field |
| --- | --- | --- |
| Sign-in and account pages | `5px` | `3px` |
| `/manage` | `10px` | `7px` |
| This site | `5px` (`--pane`) | `3px` (`--step`) |

## Spacing

| Token | Below 48rem | 48rem and up |
| --- | --- | --- |
| `--gutter`, page side padding in `/manage` | `1.25rem` (20px) | `1.5rem` (24px) |
| `--rhythm`, gap between sections in `/manage` | `1.25rem` (20px) | `1.5rem` (24px) |

## Widths

| | Max width |
| --- | --- |
| `/manage` page | `72rem` (1152px, `max-w-6xl`) |
| `/manage` prose | `60ch` to `64ch` |
| Sign-in column | `24rem` (384px) |
| Consent column | `30rem` (480px) |

## Grid and breakpoints

| Breakpoint | What changes |
| --- | --- |
| `48rem` (768px) | `/manage` moves its tab bar from the bottom to the top, and each settings section becomes two columns: `minmax(12rem, 1fr) minmax(0, 2fr)`, with a `2.5rem` gap. |
| `50rem` (800px) | This site lets code in tables wrap below this width. |
