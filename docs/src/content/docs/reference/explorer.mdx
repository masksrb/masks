The explorer below shows the same schema as the [Manage API](/reference/manage/) reference, in
GraphiQL. GraphiQL is an in-browser tool for writing GraphQL queries.

- Autocomplete, the docs pane, and validation all run against the published schema.
- Nothing on this page talks to a server.

To run a query:

1. Put your own server's `/manage/graphql` in the endpoint box.
2. Sign in to `/manage` in this browser, on the same origin.

The endpoint answers only a bearer token that carries `masks:manage` and was issued for that
tenant's manage resource. A bearer token is a token sent in the request's `Authorization` header.
