---
title: Express
description: "Sign people in to an Express app with the masksExpress middleware, and guard routes by privilege."
---

`masksExpress` from `@masks/server/express` reads the [settings](/reference/javascript/#setting-up)
every integration shares, and takes every [option](/reference/javascript/server/#options).

```ts
import express from "express";
import { masksExpress, requireAuth } from "@masks/server/express";

const app = express();

app.use(
  masksExpress({ name: "Catalog", privileges: { admin: ["catalog:admin"] } }),
);
app.get("/", (req, res) => res.json(req.masked));
app.get("/settings", requireAuth("admin"), (req, res) =>
  res.json({ subject: req.masked?.subject }),
);
```

- `masksExpress` answers the `/auth` routes and `/.well-known/oauth-protected-resource`. On every
  other request, it puts the person on `req.masked`, signed in or not.
- `requireAuth(...privileges)` guards a route by session or by access token. It needs
  `masksExpress` to run first.
- `session: false` skips reading the session on routes that `requireAuth` does not guard.
- `masks` takes a `Masks` the app already built, used in place of a new one.
