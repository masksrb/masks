---
title: Hono
description: "Sign people in to a Hono app on Node, Bun, Deno, or Cloudflare Workers with the masksHono middleware."
---

`masksHono` from `@masks/server/hono` reads the [settings](/reference/javascript/#setting-up) every
integration shares, and takes every [option](/reference/javascript/server/#options).

```ts
import { Hono } from "hono";
import { masksHono, requireAuth } from "@masks/server/hono";

const app = new Hono();

app.use(
  masksHono({ name: "Catalog", privileges: { admin: ["catalog:admin"] } }),
);
app.get("/", (c) => c.json(c.get("masked")));
app.get("/settings", requireAuth("admin"), (c) =>
  c.json({ subject: c.get("masked").subject }),
);
```

- `masksHono` answers the `/auth` routes and `/.well-known/oauth-protected-resource`. On every other
  request, it puts the person on `c.get("masked")`, signed in or not. `c.get("masked")` is typed in
  any Hono app.
- `requireAuth(...privileges)` guards a route by session or by access token. It needs `masksHono` to
  run first. A refusal is thrown as an `HTTPException` that carries the masks answer, so Hono sends
  that answer unless `app.onError` changes it.
- `session: false` skips reading the session on routes that `requireAuth` does not guard.
- `masks` takes a `Masks` the app already built, used in place of a new one.

## Cloudflare Workers

On Cloudflare Workers, `masksHono` reads `MASKS_ISSUER`, `MASKS_RESOURCE`, and `MASKS_SECRET` from the
Worker's variables and secrets. A Worker has no file to write the handshake's credentials to, so set
`MASKS_CLIENT_ID` and `MASKS_CLIENT_SECRET` as secrets, or pass a `credentials` store of your own.
See [credentials](/reference/javascript/#credentials).

Each Worker isolate keeps its own memory, so a Worker sets `store` to a
[`Store`](/reference/javascript/server/#stores) that every isolate shares. `upstashStore` reaches
Upstash with `fetch`, which a Worker has:

```ts
import { env } from "cloudflare:workers";
import { upstashStore } from "@masks/server";

app.use(
  masksHono({
    store: upstashStore({
      url: env.UPSTASH_REDIS_REST_URL,
      token: env.UPSTASH_REDIS_REST_TOKEN,
    }),
  }),
);
```
