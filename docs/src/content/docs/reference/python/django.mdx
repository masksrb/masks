It reads the [settings](/reference/python/#setting-up) every integration shares. Install the `django` extra.

## Setting up

1. Set `MASKS` in your settings to a `Config`, or to a dict of its settings:

   ```python
   MASKS = {
       "issuer": os.environ["MASKS_ISSUER"],
       "resource": "https://app.example.com",
       "name": "Catalog",
   }
   ```

2. Add the middleware after Django's own:

   ```python
   MIDDLEWARE = [
       ...,
       "django.middleware.csrf.CsrfViewMiddleware",
       "masks.django.middleware.MasksMiddleware",
   ]
   ```

3. Include the routes at the root of your URLs. The paths already start with `/auth`:

   ```python
   urlpatterns = [
       path("", include("masks.django.urls")),
       ...
   ]
   ```

4. Guard a view with a decorator:

   ```python
   from masks.django import login_required, token_required

   @login_required()
   def settings(request):
       return render(request, "settings.html", {"person": request.masked})
   ```

`login_required` and `token_required` take privileges like the [FastAPI](/reference/python/fastapi/) guards, and `login_required`
takes `tokens=True`. `request.masked` is the person on every request. Django's CSRF check stays on
for every route except back-channel logout, so a sign-out form needs `{% csrf_token %}`.

## Reference

1. Set `MASKS` in the settings to a `Config`, or to a dict of its settings.
2. Add `masks.django.middleware.MasksMiddleware` after Django's own middleware.
3. Include `masks.django.urls` at the root of the URLs.

| | |
| --- | --- |
| `request.masked` | The person on every request. |
| `@login_required(*privileges, tokens=False)` | Needs a sign-in holding each privilege, like `require` in [FastAPI](/reference/python/fastapi/). |
| `@token_required(*privileges)` | Needs an access token holding each privilege. |
| `client(request)` | A `masks.Client` with the app's credentials. |
| `start_delegation(request, provider)` | Starts a [delegation](/reference/python/#delegations). Returns the redirect. |
| `finish_delegation(request)` | Finishes it. Returns a `masks.HeldConnection`. |
| `login_url(return_to="", organization="", privilege=())` | A link that starts a sign-in. |
| `registered(request)` | Whether masks still knows the app. |
| `connected(request)` | Whether the app holds credentials. |
| `person(request)` | The person, the same as `request.masked`. |
| `engine()` | The shared engine built from `MASKS`. |

Django's CSRF check covers every route except back-channel logout.
