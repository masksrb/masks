<div class="panes">
  <div>
    <b style="color:var(--glass-amber)">server</b>
    <span>The OpenID Connect provider. It keeps its own database and a signing key for each tenant.</span>
  </div>
  <div>
    <b style="color:var(--glass-verdant)">masks</b>
    <span>The Ruby gem. It handles discovery, PKCE, the code exchange, and token verification, and includes a Rails engine.</span>
  </div>
  <div>
    <b style="color:var(--glass-cyan)">@masks/client</b>
    <span>The browser package for single-page apps. It signs in through your backend, or runs the code flow with PKCE in the page.</span>
  </div>
</div>
