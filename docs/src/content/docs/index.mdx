A standalone OpenID Connect provider with per-tenant signing keys, a Ruby gem that signs apps in
against it, and a browser package for single-page apps. Certified against the OpenID Foundation's
own test suite.

Every reference here is generated from the code it describes, so a page cannot claim something the
source does not do: the [Manage API](/reference/manage/) from `ManageSchema`,
[@masks/client](/reference/browser/) from its TypeScript, and
[Masks::Client](/api/ruby/) from the gem with SDoc. The READMEs in `server/`, `client/` and `web/`
cover running each piece.
