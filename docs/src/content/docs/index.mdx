A standalone OpenID Connect provider, a Ruby gem that signs apps in against it, and a browser
package for single-page apps. Certified against the OpenID Foundation's own test suite.

<CardGrid stagger>
  <Card title="A key per tenant" icon="seti:db">
    Every tenant gets its own RS256 keypair on create, published only at its own JWKS endpoint. A
    token from one tenant has no `kid` the next can look up.
  </Card>
  <Card title="A server, not an engine" icon="seti:config">
    `server/` runs beside your app and owns its own routes, session and cookie. The Rails engine in
    the gem is the *consumer* half, and never loads in the same process.
  </Card>
  <Card title="Apps register themselves" icon="puzzle">
    RFC 7591 dynamic client registration, plus a `/handshake` flow where a person approves an app
    and the credentials are fetched server to server.
  </Card>
  <Card title="Tokens name their API" icon="approve-check">
    RFC 8707 resource indicators put the API's URL in `aud`. A resource server checks it against its
    own URL and refuses anything else.
  </Card>
</CardGrid>
