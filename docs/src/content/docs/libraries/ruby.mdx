---
title: Masks::Client
description: The Ruby client API — issuer discovery, the code flow, token verification, registration and the handshake.
---

`masks`, in `client/`. Version `0.6.0`.

```ruby
gem "masks"
```

```ruby
require "masks"
```

`lib/masks.rb` loads `Masks::Client` always, and `Masks::Rails` only when `::Rails::Engine` is
already defined. Outside Rails the only dependency is `jwt`.

Ruby 3.2 or later.

## Entry points

```ruby
Masks::Client.issuer(url, ttl: 300)                        # => Issuer
Masks::Client.verifier(url, audience:, algorithms: nil)    # => Verifier
Masks::Client.resource(url, issuer:, **options)            # => Resource
Masks::Client.handshake(url, **options)                    # => Handshake
Masks::Client.registry                                     # => Registry
```

Each builds the class of the same name. `Session` and `Registration` are constructed directly.

## Issuer

Discovery and JWKS for one issuer URL, cached in memory.

| Constant | |
| --- | --- |
| `DISCOVERY_PATH` | `/.well-known/openid-configuration` |
| `TTL` | `300` seconds |

```ruby
Masks::Client::Issuer.normalize(url)        # => String, trailing slash removed
Masks::Client::Issuer.resolve(issuer, ttl: TTL)
```

`resolve` returns an `Issuer` unchanged and otherwise takes one from `Masks::Client.registry`, so
the cache is shared. Construct through `resolve` rather than `Issuer.new` per request.

| Method | Returns | Raises |
| --- | --- | --- |
| `#url` | the normalized issuer URL | |
| `#discovery` | the discovery document as a `Hash` | `Rejected("invalid_issuer")` if the document names a different issuer |
| `#jwks` | the JWKS document as a `Hash` | |
| `#tenant` | `discovery["tenant"]` | |
| `#endpoint(name)` | one endpoint URL from discovery | `Rejected("invalid_issuer")` if absent |
| `#avatar_styles` | `avatar_styles_supported`, else `Claims::Avatars::STYLES` | |
| `#avatar_url(subject, style: nil, size: nil)` | an avatar URL | `Rejected("invalid_style")` |
| `#refresh!` | `self`, cache emptied | |

`discovery` and `jwks` are cached separately under `TTL` and guarded by a mutex. `style` defaults to
`Claims::Avatars::FALLBACK` (`identicon`).

## Verifier

Local JWT verification against the issuer's JWKS.

```ruby
Masks::Client::Verifier.new(issuer, audience:, algorithms: ALGORITHMS)
```

`ALGORITHMS` is `%w[RS256 ES256]`. `audience` is wrapped with `Array()`.

| Method | |
| --- | --- |
| `#verify(token, required: %w[iss sub exp])` | the claims `Hash`; raises `InvalidToken` |
| `#tenant(token)` | the `tenant` claim |
| `#issuer` `#audience` | what it was built with |

`verify` checks the signature, `iss`, `aud`, expiry and the `required` claims. The JWKS loader
calls `issuer.refresh!` and refetches once when `kid` is unknown, so a key rotation is picked up
without a restart.

## Resource

The resource-server half: verify a bearer token, publish RFC 9728 metadata, build an RFC 6750
challenge.

```ruby
Masks::Client::Resource.new(
  issuer:,
  url:,
  scopes: [],
  metadata_url: nil,
  algorithms: Verifier::ALGORITHMS,
  required: REQUIRED,
  verifier: nil
)
```

| Constant | |
| --- | --- |
| `BEARER` | `/\ABearer[ \t]+([^\s,]+)[ \t]*\z/i` |
| `METADATA_PATH` | `/.well-known/oauth-protected-resource` |
| `REQUIRED` | `%w[iss sub exp]` |

`url` is this server's own identifier and becomes the audience the token must carry. `scopes`
accepts an array of names, or a `Hash` of name to description — the descriptions are published as
`scope_descriptions` and are what an auth server renders on its consent screen.

| Method | Returns | Raises |
| --- | --- | --- |
| `#authenticate(authorization, scope: nil)` | `Claims` | `Unauthenticated`, `Unauthorized`, `Forbidden` |
| `#token(authorization)` | the bearer token, or `nil` | |
| `#metadata` | the RFC 9728 document | |
| `#metadata_url` | `metadata_url:`, else the origin of `url` plus `METADATA_PATH` | |
| `#challenge(error = nil)` | a `WWW-Authenticate` value | |

`authenticate` takes the raw header value. `scope` accepts one name or an array, and each is
checked with `Claims#permit!`.

```ruby
resource = Masks::Client.resource(
  "https://app.example.com/mcp",
  issuer: "https://demo.auth.example",
  scopes: { "uris:read" => "Search your catalog" }
)

claims = resource.authenticate(request.authorization, scope: "uris:read")
claims.subject
claims.tenant.subdomain
```

`challenge` emits `error`, `error_description`, `scope` and `resource_metadata`, quoting each and
stripping control characters. A non-`Challenge` argument is wrapped as `Unauthorized`.

## Session

The consumer half: the authorization code flow, refresh, exchange, revocation and introspection.

```ruby
Masks::Client::Session.new(
  issuer:,
  client_id:,
  redirect_uri:,
  client_secret: nil,
  scope: DEFAULT_SCOPE
)
```

`DEFAULT_SCOPE` is `%w[openid profile email]`. A `client_secret` is sent as HTTP Basic on every
token-endpoint call; without one the client is public and PKCE alone authenticates it.

### start

```ruby
session.start(resource: nil, prompt: nil, scope: nil, state: …, nonce: …)
# => { url:, state:, nonce:, verifier: }
```

Generates PKCE, builds the authorization URL, and returns what must be held until the callback.
`state` and `nonce` default to `SecureRandom.urlsafe_base64(24)`. `nonce` is dropped unless the
scopes include `openid`, so holding one means an id token is owed. `resource` may be a string or an
array and repeats as `resource` parameters.

### The rest

| Method | Returns |
| --- | --- |
| `#complete(code:, verifier:, resource: nil)` | `Tokens` |
| `#refresh(refresh_token, resource: nil, scope: nil)` | `Tokens` |
| `#exchange(subject_token, scope: nil, resource: nil, lifetime: nil)` | `Tokens` |
| `#revoke(token, hint: nil)` | `true` |
| `#introspect(token, hint: nil)` | `Introspection` |
| `#userinfo(access_token)` | a claims `Hash` |
| `#identity(tokens)` | userinfo merged under the verified id token claims, or `nil` |
| `#profile(tokens)` | userinfo, or `{}` if it fails |
| `#end_session_url(post_logout_redirect_uri: nil, state: nil, id_token_hint: nil)` | a URL |

`exchange` uses `Tokens::EXCHANGE` as the grant type and `Tokens::ACCESS_TOKEN` as the subject
token type. `identity` verifies the id token against `client_id` as the audience.

## Registration

RFC 7591 registration and RFC 7592 management.

```ruby
Masks::Client::Registration.create(issuer, token: nil, **attributes)
Masks::Client::Registration.held(issuer, credentials)   # => Registration or nil
```

`create` posts to `registration_endpoint`, sending `token` as a bearer when given. `held` rebuilds
one from stored credentials and returns `nil` unless both `registration_client_uri` and
`registration_access_token` are present.

Attributes accepted, after `stringify`:

| | Default |
| --- | --- |
| `name` or `client_name` | |
| `redirect_uris` | |
| `grant_types` | `["authorization_code"]` |
| `response_types` | `["code"]` |
| `scope` | joined with spaces |
| `token_endpoint_auth_method` | |
| `application_type` `client_uri` `logo_uri` | |

Empty and nil values are dropped.

| Method | |
| --- | --- |
| `#client_id` `#client_secret` `#uri` `#access_token` `#metadata` `#issuer` | readers |
| `#read` | `GET` the registration |
| `#update(**attributes)` | `PUT` it, merging the response into `metadata`; returns `self` |
| `#delete` | `DELETE` it; returns `true` |
| `#known?` | `read` succeeded |
| `#authorization` | the bearer header `Hash` |
| `#session(redirect_uri:, scope: DEFAULT_SCOPE)` | a `Session` on these credentials |

A `401` or `403` on `read` and `update`, and those or a `404` on `delete`, are re-raised as
`Unregistered` — the issuer no longer holds this client.

## Handshake

The approval flow that connects a first-party app without anyone copying a secret.

```ruby
Masks::Client::Handshake.new(
  issuer,
  name:,
  resource:,
  redirect_uris:,
  return_to:,
  scope: Session::DEFAULT_SCOPE
)
```

| Constant | |
| --- | --- |
| `PATH` | `/handshake` |
| `GRANT_TYPES` | `%w[authorization_code refresh_token]` |
| `AUTH_METHOD` | `client_secret_basic` |

| Method | |
| --- | --- |
| `#endpoint` | `handshake_endpoint` from discovery, else the issuer URL plus `PATH` |
| `#start(state: …)` | `{ url:, state: }`; `state` defaults to `SecureRandom.urlsafe_base64(32)` |
| `#url(state:)` | the approval URL |
| `#complete(params, state:)` | a `Registration` |
| `#redeem(token)` | a `Registration` from an initial access token |

`complete` refuses in order: an `error` in the params, a `state` that does not match (compared with
`OpenSSL.secure_compare`), and an `iss` that is not this issuer — each before `redeem` runs.

```ruby
handshake = Masks::Client.handshake(
  issuer,
  name: "uris",
  resource: "https://app.example.com/mcp",
  redirect_uris: [ "https://app.example.com/auth/callback" ],
  return_to: "https://app.example.com/"
)

started = handshake.start                                   # hold started[:state]
registration = handshake.complete(params, state: held)
```

## Claims

A verified claims hash with accessors.

`AVATARS` is `"masks:avatars"`.

| Method | |
| --- | --- |
| `#[](name)` | one claim, by string or symbol |
| `#to_h` | the whole hash |
| `#subject` `#issuer` `#client_id` `#jti` `#act` | `sub`, `iss`, `client_id`, `jti`, `act` |
| `#audience` | `aud`, always an array |
| `#tenant` | `Claims::Tenant` |
| `#avatars` | `Claims::Avatars` |
| `#picture` | `picture`, else the photo, else the identicon |
| `#scopes` | `scope` split on whitespace |
| `#permits?(scope)` | `true` or `false` |
| `#permit!(scope)` | `true`, or raises `Forbidden("insufficient_scope")` |
| `#expires_at` `#issued_at` | `Time`, or `nil` |
| `#expired?(leeway: 0)` | `false` when there is no `exp` |

### Claims::Tenant

`#uuid` `#subdomain` `#name` `#present?` `#to_h` `#==`. Built from the `tenant` claim; a missing
claim yields an empty one rather than `nil`.

### Claims::Avatars

`STYLES` is `%w[photo identicon initials]`; `FALLBACK` is `identicon`.

`#photo` `#identicon` `#initials` `#[](style)` `#photo?` `#present?` `#to_h` `#==`. `photo` is
`nil` when the actor has uploaded none.

## Introspection

`Introspection < Claims`, returned by `Session#introspect`.

Adds `#active?`, `#username` and `#token_type`. `#permits?` is `false` unless the token is active,
and `#permit!` raises `Unauthorized` rather than `Forbidden` when it is not.

## Tokens

| Constant | |
| --- | --- |
| `EXCHANGE` | `urn:ietf:params:oauth:grant-type:token-exchange` |
| `ACCESS_TOKEN` | `urn:ietf:params:oauth:token-type:access_token` |

```ruby
Masks::Client::Tokens.granted(body)   # raises Rejected without an access_token
Masks::Client::Tokens.from_h(data)    # => Tokens or nil, restoring obtained_at
```

Readers: `#access_token` `#id_token` `#refresh_token` `#token_type` `#scope` `#expires_in`
`#obtained_at`.

| Method | |
| --- | --- |
| `#expires_at` | `obtained_at + expires_in` |
| `#expired?(leeway: 30)` | |
| `#scopes` | `scope` split on whitespace |
| `#authorization` | `"Bearer …"` |
| `#to_h` | round-trips through `from_h`, nils dropped |

`token_type` defaults to `Bearer`.

## Rack

Middleware that authenticates a bearer token and refuses below the framework.

```ruby
use Masks::Client::Rack, resource: resource, scope: "uris:read"
```

```ruby
Masks::Client::Rack.new(app, resource:, scope: nil, only: nil, optional: false)
```

| | |
| --- | --- |
| `resource` | a `Resource`, or a callable taking `env` |
| `scope` | a name or array required of the token |
| `only` | a callable taking `env`; the middleware is skipped when it returns falsy |
| `optional` | pass an unauthenticated request through rather than refusing |

Verified claims land in `env["masks.claims"]` (`Rack::CLAIMS`). With `optional`, an
`Unauthenticated` lands in `env["masks.error"]` (`Rack::ERROR`) and the request continues; every
other `Challenge` still refuses.

A refusal answers the challenge's status with a JSON body, `cache-control: no-store` and a
`www-authenticate` header from `Resource#challenge`.

## Errors

```
Masks::Client::Error < StandardError
├── Unreachable                     the host did not answer
├── Rejected(code, description, status:)
│   └── Unregistered                CODE = "invalid_client"
├── InvalidToken                    a JWT that does not verify
└── Challenge(code, description, status:, scope:)
    ├── Unauthenticated             401, "a bearer token is required"
    ├── Unauthorized                401, code "invalid_token"
    └── Forbidden                   403, carries scope:
```

`Rejected` carries the HTTP status when one is known. `Challenge` and its subclasses are what
`Resource#challenge` renders.

`Masks::Rails::Configuration::Unconfigured` also descends from `Masks::Client::Error`.

## Supporting classes

### Registry

Shared `Issuer` instances, keyed by normalized URL and mutex-guarded.

`#[](url, ttl: Issuer::TTL)` · `#clear!` · `#urls`

### Pkce

`METHOD` is `S256`. `Pkce.generate` builds one over `SecureRandom.urlsafe_base64(64)`.

`#verifier` · `#challenge` · `#method`

### Tracker

Short-lived state for authorizations and handshakes in flight, over a store.

`TTL` is 3600 seconds; `LIMIT` is 5 entries, oldest dropped first.

```ruby
tracker = Masks::Client::Tracker.new(store, ttl: TTL, limit: LIMIT)

entry = tracker.open(state: …, verifier: …)
tracker.amend(entry.id, nonce: …)
claimed = tracker.claim(id)   # => Entry or nil, removed on read
```

`#clear!` and `#size` round it out. Expired entries are swept on every operation.
`Tracker::Entry` carries `#id` `#data` `#opened_at` `#expires_at` `#live?` `#[]` `#to_h`.

### Stores

`Stores::Memory.new(held = {})` and `Stores::Session.new(session, key)`, each answering `#read` and
`#write`. The session store deletes its key when written an empty hash.

### HTTP

`Masks::Client::HTTP` is the `Net::HTTP` wrapper behind everything above. Open timeout 5 seconds,
read timeout 10. Every request sends `Accept: application/json` and
`User-Agent: masks/#{Masks::VERSION}`.

`get` · `post_form` · `post_json` · `put_json` · `delete`

A non-success response raises `Rejected` — or `Unregistered` when the body's `error` is
`invalid_client` — carrying `error`, `error_description` and the status. A socket, timeout or TLS
failure raises `Unreachable`.
