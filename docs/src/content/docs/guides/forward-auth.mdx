---
title: Forward authentication
description: Put masks in front of an app that has no sign-in of its own, with Caddy, Traefik, or nginx.
---

Forward authentication lets masks sign actors in to an app that has no sign-in of its own, such as a
dashboard or an admin page.

- The app sits behind a reverse proxy. A reverse proxy is a server that receives each request first
  and passes it on to the app.
- The proxy asks masks about each request.
- The proxy lets a request through only for an actor who is signed in to masks and may use the app.
- The proxy passes the actor's name along to the app in headers.

## Adding the app

1. In `/manage`, open **Clients**.
2. Choose **Add client**.
3. Choose **A known product**.
4. Pick **Any app behind Caddy, Traefik, or nginx**.
5. Enter the app's address, such as `https://dash.example.com`.

masks registers the app and shows it under **Your apps**. It lists the proxy settings for that
address below.

To limit the app to some [groups](/guides/features/#groups), use **Who may sign in** on its
**Access** tab, as for any other app.

## What happens

1. The proxy asks masks' `/forward-auth` about each request. If the request has the app's cookie,
   masks answers 200 with these headers, and the proxy hands them to the app:

   | Header | |
   | --- | --- |
   | `Remote-User` | The actor's nickname. |
   | `Remote-Email` | Their email address, when it is confirmed. |
   | `Remote-Name` | Their name. |
   | `Remote-Groups` | The [groups claim](/guides/features/#groups), separated by commas. |

2. If the request has no cookie, masks sends the browser to sign in on masks' own address. It skips
   this if the actor is already signed in to masks.
3. masks sends the browser back to `/masks-auth/callback` on the app's address, with a code. The
   code works once, for that app only, for two minutes.
4. The proxy hands that path to masks. masks sets a cookie for the app's host alone and returns the
   browser to the page it asked for.

The cookie lasts as long as the actor's masks session. Access to every app behind the proxy ends on
the next request when the actor:

- signs out of masks
- ends the session from the account page
- is suspended

Each app has its own cookie, so one app never sees another app's cookie.

## Caddy

```
dash.example.com {
  forward_auth https://auth.example.com {
    uri /forward-auth
    header_up Host auth.example.com
    copy_headers Remote-User Remote-Email Remote-Name Remote-Groups
  }
  reverse_proxy dash:8080
}
```

`header_up Host` is needed. Without it, Caddy sends the app's host to masks.

## Traefik

```yaml
http:
  middlewares:
    masks:
      forwardAuth:
        address: https://auth.example.com/forward-auth
        authResponseHeaders: [Remote-User, Remote-Email, Remote-Name, Remote-Groups]
```

Add the `masks` middleware to the app's router.

## nginx

nginx's `auth_request` cannot follow a redirect. So the nginx setup differs in two ways:

- It asks masks for a 401 and sends the browser to sign in itself.
- It hands the callback to masks with a location of its own.

```nginx
location = /masks-check {
  internal;
  proxy_pass https://auth.example.com/forward-auth?status=401;
  proxy_pass_request_body off;
  proxy_set_header Content-Length "";
  proxy_set_header X-Original-URL $scheme://$http_host$request_uri;
  proxy_ssl_server_name on;
}

location /masks-auth/ {
  proxy_pass https://auth.example.com/forward-auth/;
  proxy_set_header X-Forwarded-Host $host;
  proxy_set_header X-Forwarded-Proto $scheme;
  proxy_ssl_server_name on;
}

location / {
  auth_request /masks-check;
  auth_request_set $remote_user $upstream_http_remote_user;
  proxy_set_header Remote-User $remote_user;
  error_page 401 =302 https://auth.example.com/forward-auth/start?rd=$scheme://$http_host$request_uri;
  proxy_pass http://dash:8080;
}
```

## Headers the app can trust

The app trusts `Remote-User` only because the proxy sets it. Set up two things:

1. Make sure nothing reaches the app except through the proxy.
2. Make the proxy drop any `Remote-` header a browser sends, before it adds the headers masks
   answered with.
